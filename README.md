## Instrucciones
- Descargue el codigo en un .zip y extraigalo
- luego arranque el servidor backend con el comando "node server.js" en la carpeta raiz (/skellybackend) 
- luego arranque el servidor frontend con el comando "ionic serve" en la carpeta raiz (/skellyfrontend)
- !!ASEGURE DE INSTALAR VITE CUANDO SE ESTE ARRANCANDO EL SERVIDOR!!
## Interacciones implementadas
- Busqueda
- Edicion perfil
- Reproduccion de musica
- perfiles modularizados
- albumes modularizados
- comunidades modularizadas
