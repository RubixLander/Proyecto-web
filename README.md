## SkellyTunesIonic

## Instrucciones
- Descargue el codigo en un .zip y extraigalo, luego arranque el servidor con el comando "ionic serve" en la carpeta raiz por la terminal de VS o cmd,
- Mientras este arrancando el servidor, asegurese de instalar vite enviando por consola una "y"
  
## Interacciones implementadas
- Tanto Inicio de Sesión como registro cuentan con verificación de datos.
- Puede crear una cuenta para registrarse e iniciar sesion, la sesion quedara guardada si se sale de la pagina, aclarar, actualmente solo contamos con el perfil de [minimo] como caso de prueba
- Actualmente, las cuentas son borradas si cierra sesión, esto es provisional para evitar guardar datos innecesariamente
- La navbar de todas las paginas se encuentra funcional y linkea a todas las paginas.
- La lectura del JSON se usa en home (albumes en tendencia) y en perfil (albumes de [minimo])
- Los albumes en tendencia son aleatorios y pueden refrescarse recargando la pagina (desde el navegador)
- Actualmente, la unica comunidad disponible para ver es "Los payasos de micro"
- Actualmente, el unico perfil que se puede abrir es el de [minimo]
- Actualmente, el unico álbum que se puede "reproducir" es "失​わ​れ​た​時​REGRET" de death's dynamic shroud.wmv, aclarar, esto actualmente NO se puede realizar a través de home.
