El tipo de Base de datos que se eligió para SkellyTunes, fue de tipo relacional, esto, debido a
que este tipo de base de datos permite una mejor organización de datos en las tablas con
relaciones ya definidas, lo que facilita la representación de entidades como artistas, álbumes y
canciones.
Además de un mejor manejo, este tipo de base de datos nos permite asegurar integridad de los
datos mediante las claves primarias y foráneas, algo muy importante para evitar
inconsistencias, cómo la existencia de una canción sin estar asociada a un álbum, que una
canción no tenga artista, entre otros.
Otra de las razones de las por qué se elige este tipo de base de datos, es por las transacciones
que deben realizarse cómo la gestión de usuarios, álbumes, canciones, comunidades, entre
otras funcionalidades con las que cuenta SkellyTunes.
